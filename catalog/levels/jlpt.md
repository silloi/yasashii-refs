# 日本語能力試験の公開情報

## 何が公開されていて、何が無いか

- 公開されている: 各レベルの「認定の目安」（読む・聞くの言語行動で示したもの）、試験問題の構成、問題例、「合格者と専門家の評価によるレベル別 Can-do リスト」。
- **公開されていない: 語彙・漢字・文法項目のリストを載せた『出題基準』。** 2010年の改定以降は非公開（公式のよくある質問「2010年に試験が改定されてから、『出題基準』が非公開になったのはなぜですか。」）。代わりの情報として「認定の目安」や「試験問題の構成」を挙げている。

## 開発の参考として

- 「N3 程度」などの対象者の説明は、語彙数ではなく「認定の目安」の言語行動で書くのが公式に沿う。
- 世の中にある N1〜N5 の語彙・漢字のリスト（GitHub などで公開されているもの）は、どれも非公式。旧試験（1〜4級）の『出題基準』を元にしたものが多い。使うときは「非公式の推定」と明記し、出所を確かめる。
- **漢字は、公的資料とオープンデータだけから N5〜N1 相当の級を推定する手順がある**（作り手が確立。非公式の推定）。手順・結果・確かめたことは [docs/jlpt-kanji-levels.md](../../docs/jlpt-kanji-levels.md)。市販の日本語能力試験の漢字教材の級と比べると、主級の一致は 80.4%、第2候補まで含めると 89.5%。
- 語彙は出版社の書籍で整理されているが、公的・オープンなものは見つかっていない。
- 旧試験の漢字の級は、[KANJIDIC2](../kanji/kanjidic2.md)（CC BY-SA 4.0）の `jlpt_old` で引ける（取り込み済み）。上の推定の手順も、旧級はここから取る（『出題基準』の書籍は使わない）。1級に入っている人名用漢字251字はすべて常用外で、常用漢字の級の推定には入らない。

## 文献

### 方法の根拠

- **新しい「日本語能力試験」ガイドブック**（国際交流基金・日本国際教育支援協会、2009年）https://www.jlpt.jp/reference/pdf/guidebook1.pdf
  - 新旧の級の対応（ガイドブックでは旧試験を「現行試験」と呼んでいる）: N1 は旧1級よりやや高めのレベルまで測る。N2 は旧2級とほぼ同じ。N3 は旧2級と3級の間（新設）。N4 は旧3級、N5 は旧4級とほぼ同じ。
- **よくある質問** https://www.jlpt.jp/faq/ ：2010年の改定以降、『出題基準』（級別の漢字・語彙のリスト）は非公開。
- **CEFR レベル参考表示** https://www.jlpt.jp/about/cefr_reference.html ：日本語能力試験の総合得点に CEFR の境界を置いた参考表示（N2 は B1〜B2、N1 は B2〜C1 など）。級を決めるのには使わない。

### 精度を比べた相手（配布しない）

- 市販の日本語能力試験の漢字教材の級別のリスト（N3 350字・N2 550字・N1 800字）。
- どの字がどの級かだけを照合に使った。並び順・語彙・例文は使っていない。字の一覧はリポジトリに入れない（使うときは git 管理外の `local/` に置く）。
