# かすたねっと

外国につながりのある子どもの教育に関わる教員のために、全国の教育委員会などが作った多言語の通知文書や教材を検索できる、文部科学省のサイト。「生活・就労ガイドブック」の第5章が、外国人の子ども・保護者向けの動画とあわせて案内している。

## 何が入っているか

- **文書検索:** 学校から保護者への多言語の通知文書の例。主題は、進路・成績、費用・給付、保健、学校行事、日課・持ち物、課外活動、届出・証明書、災害・防犯、学校制度・就学、用語集。
- **教材検索:** 教科（国語・社会・算数/数学・理科・生活・外国語・日本語）と学校種で探せる教材。
- **用語検索:** 学校の言葉の多言語の用語検索（「多言語・学校プロジェクト」。Copyright Project MUSE）。
- **予定表作成:** 多言語の学校の予定表を作る道具。
- 外国人の子ども・保護者向けの動画、教員の研修用の動画、ウクライナから避難した人への支援のリンク集。
- 言語は文書によって違う。上の `languages` は主なもの（すべての言語は未確認）。

## 開発の参考として

- 学校が実際に保護者に出している通知（持ち物、行事、費用、健康診断など）の多言語の例。学校の場面で補足に出てくる言葉と言い回しを知る材料。
- 学校の言葉の訳語を確かめる手がかり（用語検索）。

## 注意

- **利用条件が2つのページで違う:**
  - 「リンク・著作権について」: 「私的使用又は引用等著作権法上認められた行為として、適宜の方法により出所を明示することにより、引用・転載複製を行うことが出来ます」。「当ホームページの内容の全部又は一部について、文部科学省総合教育政策局国際教育課日本語指導係に無断で改変を行うことはできません」。
  - 「利用規約」（平成27年3月31日改訂）第5条: 「本サイトから提供される公開情報の利用については、文部科学省ウェブサイト利用規約…に従うものとする」。ここでいう公開情報は、登録された情報のタイトル・公開主体などの目録（プロファイル）。
  - 文書と教材のファイルは、全国の教育委員会などが作ったもの。「検索されるリンク先の情報内容及び著作権は、当該公開主体または各著作権者に帰属します」。
  - そのため、リンクだけにする。使うときは、文書ごとに公開主体の条件を確かめる。
- 用語検索は、外部のプロジェクト（Project MUSE）の著作物。
- 自動での一括の取得はしない（検索の画面は JavaScript で動く）。
