# 日本語能力試験（N5〜N1）相当の漢字の級（非公式の推定）

日本語能力試験（JLPT）は、2010年の改定以降、級別の漢字リストを公開していない（目録 [jlpt](../catalog/levels/jlpt.md)）。

ここに書くのは、次の2つです。

- 公的資料とオープンデータだけから、N5〜N1 相当の漢字の級を決める手順。作り手が確立したもので、2026-11-03 に受け取った。
- その手順を、このリポジトリで確かめた結果。

手順のスクリプトは作り手が持っていて、このリポジトリには置いていません（資料を集めて参照できるようにする、というリポジトリの趣旨から外れるため）。ここには、手順の中身と、確かめた結果だけを書きます。

> 出力は公式の級ではありません。使うときは「JLPT N1 相当（非公式）」のように書きます。

## 入力（資料）

| 資料 | 使う情報 | 目録 |
| ---- | -------- | ---- |
| 常用漢字表（平成22年内閣告示） | 対象の2,136字と音訓 | [joyo-kanji-hyo](../catalog/kanji/joyo-kanji-hyo.md) |
| 音訓の小・中・高等学校段階別割り振り表（平成29年3月） | 学年（平成29年告示）と、音訓ごとの学校段階 | [onkun-warifuri](../catalog/kanji/onkun-warifuri.md) |
| 漢字出現頻度表 順位対照表 Ver.1.3 | 書籍・新聞・ウェブでの順位 | [bunka-kanji-frequency](../catalog/kanji/bunka-kanji-frequency.md) |
| KANJIDIC2 | 旧試験の級（4〜1級）、人名用漢字、異体字 | [kanjidic2](../catalog/kanji/kanjidic2.md) |
| 表外漢字字体表（データは Wikipedia の表） | 常用外の字を足すときの候補の範囲（任意） | [hyogai-jitaihyo](../catalog/kanji/hyogai-jitaihyo.md) |
| JMdict・JMnedict | 常用外の字を足すとき、名前に偏る字を除く（任意） | [jmdict](../catalog/vocabulary/jmdict.md)・[jmnedict](../catalog/vocabulary/jmnedict.md) |

方法の根拠（新旧の級の対応、公式のリストが無いこと）は、目録 [jlpt](../catalog/levels/jlpt.md) の「文献」にあります。

## 決め方

1. 対象は常用漢字 2,136字。告示の字形の 𠮟・頰・剝・塡 は、叱・頬・剥・填 にそろえる。
2. KANJIDIC2 の旧4級の字を N5（103字）、旧3級の字を N4（181字）にする。
3. 残りの1,852字を、2つの帯に分ける。
   - 前の帯: 旧2級の字。
   - 後ろの帯: それ以外（旧1級の字と、旧級の無い2010年追加の字）。
   - この分け方は、公式の説明「N2 は旧2級とほぼ同じ、N1 は旧1級よりやや高め」に沿う。
4. 5つの特徴で、帯の中をやさしい順に並べる。並べる値は、各特徴での順位の平均。
   - 学年
   - 音訓の学校段階
   - 書籍での順位
   - 新聞での順位
   - ウェブでの順位
5. 並べた順に、先頭から N3 を350字、N2 を550字、残りを N1 にする。
6. **第2候補:** 5つの特徴のそれぞれでも、同じ区切りで級を出す（5票）。主級の隣の級に2票以上入れば、その級を第2候補にする。
7. **常用外の字（任意）:**
   - 候補は、表外漢字字体表と人名用漢字の字。
   - 名前に偏る字は除く。JMdict・JMnedict の見出しにどれだけ出るかで決める。
   - 残りを書籍とウェブでの順位で並べ、上位300字を N1 に足す。
8. 計算は決定的で、同じ入力からは必ず同じ結果になる。

パラメータの既定値は、N3 の字数 350、N2 の字数 550、第2候補に要る票 2、常用外の字数 300、名前らしさの閾値 0.8（名前らしさ＝JMnedict の見出しに出る割合 ÷（JMdict と JMnedict の割合の和））。

## 結果

| N5 | N4 | N3 | N2 | N1 |
| -: | -: | -: | -: | -: |
| 103 | 181 | 350 | 550 | 1,252（うち常用外300） |

- 第2候補が付いた字は405。
- 旧級ごとの内訳:
  - N3 の350字は、すべて旧2級。
  - N2 の550字は、旧2級 389・旧1級 157・旧級なし 4。
  - N1 の常用漢字952字は、旧1級 799・旧級なし 153。
- 旧級の無い常用漢字157字は、すべて2010年の改定で加わった字。
  - 154字は、表外漢字字体表の字が常用漢字になったもの。
  - 残る「楷・憬・錮」は、人名用漢字でも表外漢字字体表の字でもなかった追加字（JAGAT の記事 https://www.jagat.or.jp/past_archives/content/view/5684.html ）。

## 精度（作り手の検証）

市販の JLPT 漢字教材の級別のリスト（N3 350字・N2 550字・N1 800字、計1,700字）と比べた。

| 指標 | 値 |
| ---- | -- |
| 主級が一致 | 80.4% |
| 主級か第2候補が一致 | 89.5%（N3 86%、N2 82%、N1 96%） |
| 一致しなくても隣の級 | 出力に入った字の100% |
| 出力に入らなかった字 | 常用外の8字（全体の0.5%） |

- N3 350字・N2 550字という字数は、その教材に合わせた。それ以外の規則は、教材を見ずに決めた。
- 公式のリストが無いので、これは「正解との一致率」ではない。「公的資料から説明できる推定」が、市販教材とどれだけ合うかを示す数字。
- 比べた相手の字の一覧は、リポジトリに入れない。

## このリポジトリで確かめたこと（2026-11-03）

1. **同じ表を作り直せる:** 受け取った手順をブラウザなしで動かした（pdf.js 3.11.174 を Node で使用。そのとき使ったスクリプトも、このリポジトリには置いていない）。手順の中で作る4つの表（常用漢字表・割り振り表・頻度表・表外漢字字体表）は、作り手が記録した SHA-256 と1バイトも違わなかった。
2. **EDRDG のデータの版を変えても、結果の字数は同じ:**
   - 作り手は2021年版のデータで検証した。こちらは2026-11-03の版のデータを使った。
   - 級ごとの字数・第2候補の数・常用外の数は同じだった。上の「結果」の内訳も、出力で確かめた。
   - 2021年版のデータで作った出力は受け取っていないので、字ごとの一致までは確かめていない。
3. **このリポジトリで取り込んだデータと一致する:**
   - **常用漢字表**（`data/joyo-kanji-hyo.jsonl`）: 2,136字の並び、音訓4,388、1字下げの印が、手順の表と一致した。
     - 違いは、康熙字典体の3字（亀の龜、弁の辨・瓣・辯、剤の劑）が手順の表では空欄だったことだけ。
     - pdf.js では、括弧と字が別々に出てくるか（剤・弁）、字が取り出せない（亀）ため。
     - これらの字は出力に入らないので、結果は変わらない。
   - **割り振り表:** 字の並び・学年・音訓の並び・1字下げの印が、`data/joyo-kanji-hyo.jsonl`・`data/gakunen-kanji.jsonl` と一致した。
   - **KANJIDIC2**（`data/kanjidic2.jsonl`）: 学年・旧級・頻度が、手順の抽出（`kanjidic_min.csv`）と一致した。
   - **字形をそろえた字:** 叱・頬・剥・填には KANJIDIC2 の旧級が無く、告示の字形（𠮟・頰・剝・塡）にも無い。字形をそろえても、旧級の判定は変わらない。

## 気づいたこと（2026-11-03）

- **頻度の順位に、別の字の順位が入ることがある。**
  - 手順のスクリプト（`build_levels.py`）は、頻度表の順位を引くときに字形をまとめる。まとめるのに使うのは、表外漢字字体表の字と、KANJIDIC2 の異体字（JIS X 0208）。
  - 異体字の関係にあっても、使われ方は別の字（「埼」「阪」は地名にしか使わない）なので、このまとめ方は直した方がよい（作り手に伝える）。
  - 「埼」には「崎」の順位が入る（書籍 590・ウェブ 553。「埼」自身は 2,090・1,320）。KANJIDIC2 が「崎・碕・嵜」を「埼」の異体字としているため。
  - 「阪」には「坂」の順位が入る（586・833。「阪」自身は 855・497）。KANJIDIC2 が「坂」を「阪」の異体字としているため。
  - 「痩」「麺」は、表外の字形（瘦・麵）の行が先に読まれる。そのため、ウェブの順位が空になる。
- **常用漢字だけなら、表外漢字字体表・JMdict・JMnedict が無くても主級は同じ。**
  - これらを使わずに作る（`--extra-top-k 0`、表外漢字字体表は空）と、主級は2,136字すべて同じだった。
  - 変わるのは第2候補の3字（埼・閣・塚）だけ。このとき頻度は、どの字も自分の行の順位になる。
