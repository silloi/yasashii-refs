# 分野と言語の優先順位

外国人住民・在留外国人の、市民生活の困りごとを解決することを優先する。そのための分野と言語の順番を、公的な統計と調査に、影響の大きさの見方を加えて決める（2026-11-03 時点）。

## 分野

分野の分け方は、出入国在留管理庁「生活・就労ガイドブック」（第8版、2026年2月）の章に合わせる。目録の `domains` にはこの名前を使う（分野を問わない資料は `全般`）。

2つの見方を合わせて決める。

- **頻度:** 関係する人の多さと、調査で困った人の割合
- **影響の大きさ:** 命・在留資格・お金に関わるか、間違えたときに取り返しがつくか。いざというときに調べる時間があるか

| 順位 | 分野（ガイドブックの章） | 理由（数値は「在留外国人に対する基礎調査」令和6年度、有効回答 7,621件） |
| ---- | ------------------------ | ------------------------------------------------------------ |
| 1 | 入国・在留手続（第1章） | 在留する全員に関係し、期限がある。間違えると在留そのものに影響する |
| 2 | 緊急・災害（第10章） | 命に関わり、起きてからでは調べる時間が無い（前もって分かっている必要がある）。「信頼できる情報をどこから得ればよいか分からなかった」7.0%、北陸地方（令和6年能登半島地震）では「避難場所が分からなかった」11.8%が最多。頻度は低いが影響が最も大きいので上げた（作り手の判断） |
| 3 | 医療（第6章） | 命・健康に関わる。「症状に合う病院がどこにあるのか分からなかった」10.3%、「症状を正確に伝えられなかった」10.2% |
| 4 | 市区町村での手続（第2章） | 公的機関に相談するとき「どこに相談すればよいか分からなかった」16.2%（困りごとの最多）。公的機関の情報を得るとき「ウェブサイトで必要な情報にたどり着くことが難しかった」9.3% |
| 5 | 年金・福祉（第7章）、税金（第8章） | お金に関わり、後から気づくと取り返しにくい。介護保険の困りごとの最多が「制度の詳しい内容がよくわからない」36.6% |
| 6 | 出産・子育て（第4章）、教育（第5章） | 妊娠・出産の困りごと「費用が高い」8.5%、「子どもが生まれた後、どのような手続を行えばいいのかわからない」4.5% |
| 7 | 雇用・労働（第3章） | 仕事の困りごと「給料が低い」33.3%。必要な支援の2位が「仕事」47.2% |
| 8 | 住居（第11章） | 差別を受けた場面の最多が「家を探すとき」17.4% |
| 9 | 交通（第9章）、日常生活のルール・習慣（第12章） | — |

- 必要な支援・取組（複数回答）の最多は「言語」57.7%。公的機関の情報を得るときの困りごとの最多は「多言語での情報発信が少なかった」17.0%。
- 外国人支援のウェブページや取組を「知らない」人が8割を超える。資料を作るだけでなく、届け方も課題。
- 出典: 出入国在留管理庁「令和６年度 在留外国人に対する基礎調査」の主な結果（https://www.moj.go.jp/isa/content/001436042.pdf ）、報告書（https://www.moj.go.jp/isa/content/001436052.pdf ）。
- 調査の割合は分野ごとの設問の答えで、分野どうしを直接比べたものではない。

### 歴史的な経緯（特別永住者と日系人）

作り手の指摘では、韓国語とポルトガル語が公的な案内で重視されてきた背景に、法律で定めた在留の地位がある。その地位と人数を、下の資料で確かめた（2026-11-03）。

- **特別永住者（韓国語）**
  - 入管特例法は、平和条約で日本の国籍を離れた人のうち、昭和20年9月2日以前から日本に住み続けている人など（第2条）と、その子孫を対象にする。この人たちは「特別永住者として、本邦で永住することができる」（第2条・第3条）。法律は国の名前を挙げていない。
  - 出入国管理基本計画（第2次、平成12年）は「いわゆる在日韓国・朝鮮人を主とする特別永住者」と書いている。特別永住者に当たる外国人は、戦後から昭和30年代まで、外国人登録者の「9割近く」だった。
  - 令和8年6月末の特別永住者は 263,705人。韓国 238,998人（90.6%）、朝鮮 21,314人（8.1%）、台湾 984人（0.4%）。
  - 特別永住者がふだん使う言語の統計は未確認。市区町村の一元的相談窓口で使われた韓国語は 1,888件（令和7年度、全体の0.4%）。
- **日系人（ポルトガル語・スペイン語）**
  - 「定住者」の在留資格は、平成2年（1990年）6月施行の改正入管法で整えられた。日系人の大部分は「日本人の配偶者等」か「定住者」で在留し、どちらも入管法上の活動の制限が無い（出入国管理基本計画（第2次））。内閣府の年次経済財政報告（令和6年度）も、この改正を「日系ブラジル人・日系ペルー人といった日系人等を対象とした制度の整備」と書いている。
  - 「定住者」に当たる地位は定住者告示（平成2年法務省告示第132号）が定める。日系人に関わるのは第3号（日本人の子として出生した者の実子）、第4号（日本人の子として出生した者でかつて日本国民として本邦に本籍を有したことがあるものの実子の実子）など。ほかに第三国定住難民（第1号）、中国残留邦人等とその親族（第8号）も含む。
  - 出入国在留管理庁は「定住者」の該当例に「日系３世」を挙げている。日本人の子として生まれた日系2世は「日本人の配偶者等」に当たる（告示の第5号イ「日本人の配偶者等の在留資格をもって在留する者で日本人の子として出生したものの配偶者」を、同庁は「日系２世の配偶者」と案内している）。
  - 告示の第3号・第4号と世代の対応は、資料によって書き方が違う（規制改革の資料では、第3号を「いわゆる日系２世」、第4号を「いわゆる日系３世」としている）。世代の数え方には立ち入らない。
  - 平成10年末の「定住者」の外国人登録者は 211,275人で、ブラジルが 115,536人（約55%）だった（出入国管理基本計画（第2次））。
  - 令和7年12月末の「定住者」226,438人のうち、日系3世は 54,940人。内訳はブラジル 35,432人（64.5%）、フィリピン 10,003人（18.2%）、ペルー 4,508人（8.2%）。「日本人の配偶者等」の「日本人の実子又は特別養子」25,125人のうち、ブラジルは 12,596人（50.1%）。
  - ブラジル国籍の在留外国人は令和8年6月末に 209,550人。永住者 118,580人、定住者 67,723人、日本人の配偶者等 13,660人で、合わせて95%を超える。
  - 人数は平成26年末の 175,410人から令和2年末の 208,538人まで増え、その後は21万人前後で横ばい。増減の要因は未確認。この統計は外国籍の人だけを数える。日本国籍を取った人や、日本国籍の子は入らない。
- **在留期間**
  - 特別永住者と永住者には、在留期間が無い（永住者は「無期限」）。特別永住者証明書には有効期間があり更新の申請が要るが、これは証明書の更新で、在留の期間ではない。
  - 定住者（5年・3年・1年・6月か、5年を超えない範囲で個々に指定）と日本人の配偶者等（5年・3年・1年・6月）には在留期間があり、更新の許可が要る。
  - ブラジル国籍の人では、永住者が56.6%（118,580人、令和8年6月末）。
- 出典:
  - 日本国との平和条約に基づき日本の国籍を離脱した者等の出入国管理に関する特例法（平成3年法律第71号。https://laws.e-gov.go.jp/law/403AC0000000071 ）

  - 内閣府「年次経済財政報告」（令和6年度）第2章第3節（https://www5.cao.go.jp/j-j/wp/wp-je24/h02-03.html ）、内閣府「規制改革・民間開放推進3か年計画（再改定）」（平成18年3月）の別表2（https://www8.cao.go.jp/kisei-kaikaku/old/publication/2005/0331/item050331_04-02.pdf ）

### 併記する言語の順番（案）

1. **第1群:** ベトナム語、中国語（簡体字）、英語、フィリピノ語、ネパール語、インドネシア語、ポルトガル語、韓国語、ミャンマー語
   - 在留外国人・外国人労働者の上位9か国の言語。英語は共通の言語としても使われる。
   - 1位は統計によって違う。外国人労働者ではベトナム（605,906人）が中国（431,949人）を上回る（令和7年10月末）。在留外国人全体では中国（941,031人）がベトナム（693,750人）を上回る（令和8年6月末）。
   - 公的な案内では、伝統的に英語・中国語・韓国語が重視されてきた（作り手の指摘）。この3言語も第1群に入っている。
   - ポルトガル語も、それに次いで歴史的な経緯で重視されてきた言語の一つ（上の「歴史的な経緯」）。在日ブラジル人の多い地域では、いまも需要が多い（作り手の指摘。市区町村の相談では最多。上の「相談の場面で使われている言語」）。
   - 基礎調査の回答画面（ルビ付きの日本語、英語、中国語、韓国語、ポルトガル語、ベトナム語、フィリピノ語、ネパール語、インドネシア語）とほぼ同じ。
2. **第2群:** スペイン語、タイ語、中国語（繁体字）、クメール語、モンゴル語
   - スペイン語は、市区町村の相談の場では中国語・ベトナム語より多く使われている（上の「相談の場面で使われている言語」）が、第2群のままにする（作り手の判断、2026-11-03）。ポルトガル語と近縁で、国内ではポルトガル語よりも地域の偏りが大きいため。
3. **第3群（将来の必要性が高い）:** シンハラ語、ベンガル語、ウルドゥー語（タミル語も）
   - いまの人数では下位だが、伸びが大きく、日本語教育機関で学ぶ人（これから働く人）も増えている。
   - 「生活・就労ガイドブック」の言語版に無い。公的な多言語資料が手薄な言語。
   - 将来の必要性は、ロシア語・ウクライナ語より高いと見る（作り手の判断）。
4. ガイドブックにはあるが、在留外国人の人数では下位の言語: ヒンディー語、トルコ語、ウクライナ語、ロシア語、フランス語

## 公的な資料が足りないところ

- **言語:** シンハラ語・ベンガル語・ウルドゥー語の公的な生活情報が少ない（「生活・就労ガイドブック」の言語版に無い）。防災の多言語の情報（気象庁の多言語のページ・防災庁のチラシは、どれも同じ15言語）にも、医療機関の多言語の説明資料（厚生労働省、13言語。ヒンディー語・アラビア語・ウクライナ語はある）にも無い。
  - 出産・子育て・教育では、第1群の言語にも抜けがある。母子健康手帳の多言語版（こども家庭庁、10か国語）にミャンマー語が無い。外国人児童生徒のための就学ガイドブック（文部科学省、8言語。2015年の版）にネパール語・インドネシア語・ミャンマー語が無い（2026-11-04）。
  - 雇用・労働は、第1群の言語がおおむねそろっている。雇用管理に役立つ多言語用語集は14言語（ミャンマー語・インドネシア語・ネパール語・カンボジア語・モンゴル語を含む）、外国人労働者向けの相談ダイヤルと労働条件相談ほっとライン、モデル労働条件通知書は13言語。ただし、ハローワークに外国語で電話できる10言語にはミャンマー語が無い。どれにもシンハラ語・ベンガル語・ウルドゥー語は無い（スリランカの外国人労働者は前年比 +28.9%）（2026-11-04）。
  - 住居も、第1群の言語がそろっている。国土交通省の部屋探しのガイドブック・原状回復のポイント・契約書等の見本は14言語（ミャンマー語・ネパール語・インドネシア語・クメール語・モンゴル語を含む）。シンハラ語・ベンガル語・ウルドゥー語は無い（2026-11-04）。
  - **例外:** 第3群の言語の版がある国の資料は、この目録では2つ（ベンガル語はどちらにも無い）。
    - 警察庁の交通ルールと運転免許の案内（2026年、20言語）。シンハラ語・ウルドゥー語・ヒンディー語・ペルシア語・アラビア語を含む。
    - 出入国在留管理庁の特定技能総合支援サイト（やさしい日本語と13言語）。シンハラ語・ウルドゥー語を含む。
  - 国以外の資料では、多言語医療問診票（NPO・公益財団法人、23言語）にシンハラ語・タミル語がある。ただし営利目的の使用は禁止（2026-11-04）。
  - 出産・子育て・日常の抜け: 児童手当の外国語の案内は、こども家庭庁のサイトに見つからない。携帯電話の契約の注意も、国の多言語の資料は見つからない（総務省には2019年の取組の資料だけ）（2026-11-04）。
  - 日常（銀行口座・送金）の金融庁のチラシは、やさしい日本語と16言語（ミャンマー語・クメール語・ネパール語・トルコ語・ウクライナ語を含む）。自賠責保険・共済のポータルサイトは6言語で、フィリピノ語・ネパール語・インドネシア語・ミャンマー語が無い（2026-11-04）。
- **日本語能力試験の語彙・漢字のリスト:** 2010年の改定以降、語彙・漢字・文法項目のリストを載せた『出題基準』は非公開（日本語能力試験のよくある質問）。N1〜N5 の語彙・漢字のリストは、どれも非公式の推定。旧試験（1〜4級）のリストを元にしたものが多い。
  - 漢字は、公的資料とオープンデータだけから N5〜N1 相当の級を推定する手順がある（作り手が確立。非公式の推定。[docs/jlpt-kanji-levels.md](jlpt-kanji-levels.md)）。市販の JLPT 漢字教材の級と比べて、主級の一致は 80.4%、第2候補まで含めると 89.5%。
  - 語彙は、出版社の書籍（対策本など）で整理されているが、公的・オープンなものは見つかっていない。
  - 教育の専門家が難易度を付けた語彙表として「日本語教育語彙表」（17,908語、6段階）があるが、研究・教育のための利用に限られ、二次配布もできない（目録 [nihongo-kyoiku-goihyo](../catalog/vocabulary/nihongo-kyoiku-goihyo.md)）。商用やデータの公開に使うには相談が要る。
- **生活困窮の相談窓口の一覧:** 生活困窮者自立支援制度の自立相談支援機関の窓口の一覧は、厚生労働省のページから、民間の一般社団法人（生活困窮者自立支援全国ネットワーク）が運営するサイト（「All Right Reserved」）に案内されている。オープンなデータとして参照できる一覧が無い（2026-11-03）。
- **福祉（介護保険・障害福祉・生活保護）の多言語の資料:** 「生活・就労ガイドブック」の第7章が案内する厚生労働省のページは日本語だけ。
- **市区町村の戸籍の届出・印鑑登録:** 婚姻・離婚・死亡の届出と印鑑登録は、国の多言語の資料が見つからない。「生活・就労ガイドブック」も、市区町村や大使館への問い合わせを案内するだけ。資料を使ったウェブサービスで解決したい対象（作り手の指摘）。
