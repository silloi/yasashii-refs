# 分野と言語の優先順位

外国人住民・在留外国人の、市民生活の困りごとを解決することを優先する。そのための分野と言語の順番を、公的な統計と調査に、影響の大きさの見方を加えて決める（2026-11-03 時点）。

## 分野

分野の分け方は、出入国在留管理庁「生活・就労ガイドブック」（第8版、2026年2月）の章に合わせる。目録の `domains` にはこの名前を使う（分野を問わない資料は `全般`）。

2つの見方を合わせて決める。

- **頻度:** 関係する人の多さと、調査で困った人の割合
- **影響の大きさ:** 命・在留資格・お金に関わるか、間違えたときに取り返しがつくか。いざというときに調べる時間があるか

| 順位 | 分野（ガイドブックの章） | 理由（数値は「在留外国人に対する基礎調査」令和6年度、有効回答 7,621件） |
| ---- | ------------------------ | ------------------------------------------------------------ |
| 1 | 入国・在留手続（第1章） | 在留する全員に関係し、期限がある。間違えると在留そのものに影響する |
| 2 | 緊急・災害（第10章） | 命に関わり、起きてからでは調べる時間が無い（前もって分かっている必要がある）。「信頼できる情報をどこから得ればよいか分からなかった」7.0%、北陸地方（令和6年能登半島地震）では「避難場所が分からなかった」11.8%が最多。頻度は低いが影響が最も大きいので上げた（作り手の判断） |
| 3 | 医療（第6章） | 命・健康に関わる。「症状に合う病院がどこにあるのか分からなかった」10.3%、「症状を正確に伝えられなかった」10.2% |
| 4 | 市区町村での手続（第2章） | 公的機関に相談するとき「どこに相談すればよいか分からなかった」16.2%（困りごとの最多）。公的機関の情報を得るとき「ウェブサイトで必要な情報にたどり着くことが難しかった」9.3% |
| 5 | 年金・福祉（第7章）、税金（第8章） | お金に関わり、後から気づくと取り返しにくい。介護保険の困りごとの最多が「制度の詳しい内容がよくわからない」36.6% |
| 6 | 出産・子育て（第4章）、教育（第5章） | 妊娠・出産の困りごと「費用が高い」8.5%、「子どもが生まれた後、どのような手続を行えばいいのかわからない」4.5% |
| 7 | 雇用・労働（第3章） | 仕事の困りごと「給料が低い」33.3%。必要な支援の2位が「仕事」47.2% |
| 8 | 住居（第11章） | 差別を受けた場面の最多が「家を探すとき」17.4% |
| 9 | 交通（第9章）、日常生活のルール・習慣（第12章） | — |

- 必要な支援・取組（複数回答）の最多は「言語」57.7%。公的機関の情報を得るときの困りごとの最多は「多言語での情報発信が少なかった」17.0%。
- 外国人支援のウェブページや取組を「知らない」人が8割を超える。資料を作るだけでなく、届け方も課題。
- 出典: 出入国在留管理庁「令和６年度 在留外国人に対する基礎調査」の主な結果（https://www.moj.go.jp/isa/content/001436042.pdf ）、報告書（https://www.moj.go.jp/isa/content/001436052.pdf ）。
- 調査の割合は分野ごとの設問の答えで、分野どうしを直接比べたものではない。

### 併記する言語の順番（案）

1. **第1群:** ベトナム語、中国語（簡体字）、英語、フィリピノ語、ネパール語、インドネシア語、ポルトガル語、韓国語、ミャンマー語
   - 在留外国人・外国人労働者の上位9か国の言語。英語は共通の言語としても使われる。
   - 1位は統計によって違う。外国人労働者ではベトナム（605,906人）が中国（431,949人）を上回る（令和7年10月末）。在留外国人全体では中国（941,031人）がベトナム（693,750人）を上回る（令和8年6月末）。
   - 公的な案内では、伝統的に英語・中国語・韓国語が重視されてきた（作り手の指摘）。この3言語も第1群に入っている。
   - 基礎調査の回答画面（ルビ付きの日本語、英語、中国語、韓国語、ポルトガル語、ベトナム語、フィリピノ語、ネパール語、インドネシア語）とほぼ同じ。
2. **第2群:** スペイン語、タイ語、中国語（繁体字）、クメール語、モンゴル語
3. **第3群（将来の必要性が高い）:** シンハラ語、ベンガル語、ウルドゥー語（タミル語も）
   - いまの人数では下位だが、伸びが大きく、日本語教育機関で学ぶ人（これから働く人）も増えている。
   - 「生活・就労ガイドブック」の言語版に無い。公的な多言語資料が手薄な言語。
   - 将来の必要性は、ロシア語・ウクライナ語より高いと見る（作り手の判断）。
4. ガイドブックにはあるが、在留外国人の人数では下位の言語: ヒンディー語、トルコ語、ウクライナ語、ロシア語、フランス語

## 公的な資料が足りないところ

- **言語:** シンハラ語・ベンガル語・ウルドゥー語の公的な生活情報が少ない（「生活・就労ガイドブック」の言語版に無い）。
- **日本語能力試験の語彙・漢字のリスト:** 2010年の改定以降、語彙・漢字・文法項目のリストを載せた『出題基準』は非公開（日本語能力試験のよくある質問）。N1〜N5 の語彙・漢字のリストは、どれも非公式の推定。旧試験（1〜4級）のリストを元にしたものが多い。
  - 漢字は、公的資料とオープンデータだけから N5〜N1 相当の級を推定する手順がある（作り手が確立。非公式の推定。[docs/jlpt-kanji-levels.md](jlpt-kanji-levels.md)）。市販の JLPT 漢字教材の級と比べて、主級の一致は 80.4%、第2候補まで含めると 89.5%。
  - 語彙は、出版社の書籍（対策本など）で整理されているが、公的・オープンなものは見つかっていない。
  - 教育の専門家が難易度を付けた語彙表として「日本語教育語彙表」（17,908語、6段階）があるが、研究・教育のための利用に限られ、二次配布もできない（目録 [nihongo-kyoiku-goihyo](../catalog/vocabulary/nihongo-kyoiku-goihyo.md)）。商用やデータの公開に使うには相談が要る。
- **言い換え例:** 「在留支援のためのやさしい日本語ガイドライン」別冊「やさしい日本語書き換え例」は、辞書に近い形だが網羅的ではない。
