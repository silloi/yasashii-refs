# yasashii-refs

外国人住民・在留外国人・日本語学習者のためのアプリを作るときに参照する、**やさしい日本語・行政用語・多言語の生活情報・漢字や語彙のレベル**などの資料の目録です。人と AI エージェントの両方が読める形で整理します。

## 2つの使い道

1. **開発の参考（いま重視しているもの）:** 何を作るか・どう作るかを決めるときに引く資料。
   - どんな公的資料があるか
   - どれが正式な出典か
   - 使ってよい条件
   - どの言語・どの分野が足りていないか
2. **アプリの資源（将来）:** アプリが実行時に引くデータ（用語の対訳、言い換え例、漢字のレベルなど）。
   - 使ってよい条件を確かめたものだけを、共通の形に変えて置く

## 中身

| 場所 | 内容 |
| ---- | ---- |
| [`catalog/`](catalog/README.md) | 目録。1つの資料につき1ファイル（Markdown の前付けに、提供元・形式・ライセンス・扱いを書く） |
| [`docs/priorities.md`](docs/priorities.md) | 分野と言語の優先順位と、その根拠（統計・調査） |
| [`docs/language-coverage.md`](docs/language-coverage.md) | 資料ごとの言語の対応の一覧表（目録の前付けから `scripts/language_table.py` で作る） |
| [`docs/jlpt-kanji-levels.md`](docs/jlpt-kanji-levels.md) | 日本語能力試験（N5〜N1）相当の漢字の級の推定（非公式）の手順・結果・確かめたこと |
| [`data/`](data/README.md) | 取り込める資料を共通の形（JSONL）に変えたもの。各項目に資料の id と版、出典は `*.meta.json` に |
| `scripts/` | 配布元から取得して変換するスクリプト（Python 標準ライブラリだけ）と、目録・リンクの確認 |
| `tests/` | データの確認（`python3 -m unittest discover -s tests`） |

エージェントの作業の決まりは [CLAUDE.md](CLAUDE.md) にあります。

## 資料の扱い

| 扱い | 意味 |
| ---- | ---- |
| `ingest`（取り込む） | 再配布できることを確かめたもの。`data/` に取り込める（出典・版・取得日を残す） |
| `link`（リンクだけ） | 目録に載せて参照するが、中身は置かない（規約が分からない、再配布できない、更新が速い など） |
| `outreach`（相談の候補） | 非商用に限る（NC）など、そのままでは使いにくいもの。権利者への相談を考える候補として記録する |
| `exclude`（扱わない） | 目的に合わないと判断したもの（理由を書く） |

- 商用で使えない資料（NC 条件など）は、データとして取り込まない。目録には載せ、相談の候補にする。
- 公的機関のサイトの多くは「公共データ利用規約（第1.0版）」（PDL1.0、CC BY 4.0 と互換）で、出典を書けば商用も含めて取り込める。ただし、ロゴや第三者の権利があるものは別。
- 告示（常用漢字表、学習指導要領など）は著作権の対象ではない（著作権法第13条）。
